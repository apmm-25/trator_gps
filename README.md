# trator_gps
Firmware for an ESP32-based board to control an output based on GPS information.

## Repository structure

- `ESP32_firmware/`
  - `trator_gps_firmware/`
    - `CMakeLists.txt`
    - `main/`
      - `hello_world_main.c`
    - `sdkconfig`
    - `sdkconfig.ci`
    - `build/` (generated by ESP-IDF)
    - `.clangd`
